# Портфолио — ivansereda.fr

Статический сайт фотографа Ивана Середы (EN/FR). Тексты и список серий — в `build.py`, фото — в `images.txt`
(скачиваются и уменьшаются на сервере). Установка и обновление:

```
git clone https://github.com/ivansereda91-dotcom/portfolio /opt/portfolio
bash /opt/portfolio/setup.sh
```
